# `wsb-wezterm` module

The wsb-wezterm module is the primary module that exposes wsb-wezterm configuration
and control to your config file.

You will typically place:

```lua
local wezterm = require 'wsb-wezterm'
```

at the top of your configuration file to enable it. This documentation refers to
the module through that variable: `wezterm.<name>` is the module's `<name>`.
