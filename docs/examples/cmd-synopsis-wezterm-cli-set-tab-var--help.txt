Set or remove a variable of a tab, which programs in its panes cannot change

Usage: wezterm cli set-tab-var [OPTIONS] <NAME> [VALUE]

Arguments:
  <NAME>
          The name of the variable

  [VALUE]
          The value to set the variable to

Options:
      --tab-id <TAB_ID>
          Specify the target tab by its id

      --pane-id <PANE_ID>
          Specify the current pane. The default is to use the current pane based on the environment variable WEZTERM_PANE.
          
          The pane is used to figure out which tab to set the variable on.

      --unset
          Remove the variable instead of setting it

  -h, --help
          Print help (see a summary with '-h')
